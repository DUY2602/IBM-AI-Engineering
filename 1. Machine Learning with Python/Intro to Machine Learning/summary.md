# Artificial Intelligence & Machine Learning Overview

## Introduction

**Artificial Intelligence (AI)** simulates human cognition, while **Machine Learning (ML)** uses algorithms and requires feature engineering to learn from data.

---

## Types of Machine Learning Models

Machine learning includes several main types of models:

| Type                         | Description                              |
| ---------------------------- | ---------------------------------------- |
| **Supervised Learning**      | Uses labeled data to make predictions    |
| **Unsupervised Learning**    | Finds patterns in unlabeled data         |
| **Semi-supervised Learning** | Trains on a small subset of labeled data |

---

## Choosing a Machine Learning Technique

Key factors to consider when selecting a machine learning technique:

- Type of problem to be solved
- Available data
- Available resources
- Desired outcome

---

## Common Machine Learning Techniques

| Technique             | Purpose                                     |
| --------------------- | ------------------------------------------- |
| **Anomaly Detection** | Identifying unusual cases (e.g., fraud)     |
| **Classification**    | Categorizing new data                       |
| **Regression**        | Predicting continuous values                |
| **Clustering**        | Grouping similar data points without labels |

---

## Deep Learning Frameworks

Frameworks that support the design, training, and testing of neural networks:

- **TensorFlow**
- **Keras**
- **Theano**
- **PyTorch**

These are widely used in areas such as **computer vision** and **natural language processing**.

---

## Computer Vision & Natural Language Processing

### Computer Vision

Enables applications such as:

- Object detection
- Image classification
- Facial recognition

### Natural Language Processing (NLP)

Popular tools include:

- **NLTK**
- **TextBlob**
- **Stanza**

These facilitate text processing, sentiment analysis, and language parsing.

---

## Generative AI

**Generative AI** tools use artificial intelligence to create new content — including text, images, music, and other media — based on input data or prompts.

---

- Exporting models for production use
